How each access works

CPU gives address → split into tag | index | offset → index picks the set (direct: one line, associative: only one set) → compare tag with every valid line in the set → match: HIT, read byte at offset → no match: MISS, fetch whole block from main memory → use an empty line, otherwise evict a victim (LRU or FIFO; direct mapped has no choice) → update the line and return the data.
